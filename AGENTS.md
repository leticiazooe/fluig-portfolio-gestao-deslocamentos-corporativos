# Manutenção deste case

Este repositório é um projeto independente de portfólio com dados fictícios.

- Use a nomenclatura registrada em docs/proveniencia.md e aplique renomeações por significado.
- Edite as fontes listadas no README e regenere as saídas; não corrija um evento gerado isoladamente.
- Preserve a distinção entre obrigação legal antes de circular e política interna de abastecimento no retorno.
- Não acrescente liberação alternativa para falha crítica nem alegue homologação não executada.
- Mantenha códigos de atividades, campos, eventos, condições e BPMN consistentes.
- Execute npm run generate, npm run check e npm test para alterações de código ou configuração.
- Nunca inclua credenciais, pessoas reais, conexões privadas ou arquivos corporativos.
- Não publique com force push nem altere o repositório de referência.
